# MangaMorph

MangaMorph é um protótipo de plataforma moderna para descoberta e organização de mangás.

## v0.1

A primeira versão inclui:

- interface responsiva para celular e desktop;
- catálogo demonstrativo com filtros;
- busca instantânea;
- favoritos salvos no navegador;
- tema claro/escuro;
- estrutura SEO básica;
- manifesto PWA e cache offline leve;
- sitemap e robots.txt.

## Estrutura

```text
mangamorph/
├── index.html
├── manifest.webmanifest
├── sw.js
├── robots.txt
├── sitemap.xml
└── assets/
    ├── css/
    │   └── style.css
    └── js/
        └── app.js
```

> Os títulos exibidos na v0.1 são fictícios e servem apenas para demonstrar a interface.

Próximas etapas: página individual de obra, leitor, dados reais via API/backend, autenticação e sincronização da biblioteca.
